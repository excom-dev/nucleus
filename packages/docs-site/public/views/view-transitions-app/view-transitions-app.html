Card expansion

Click a card. One write flips is-open; the box morphs because its name is the same before and after.

  • Alpha

    The open card spans the row. Its group animates size and position; nothing else is named, so the rest crossfades.

  • Beta

    Every card has its own view-transition-name, written by the sheet as a CSS variable.

  • Gamma

    Click the open card again to close it: the same write, the same morph, in reverse.

  • Delta

    Types name the cut, so CSS can tune the open and the close differently.

Page slide

The current page carries is-current. The transition type says which way you went, and the CSS slides accordingly.

One

Forward slides the old page out to the left and the new one in from the right.

Two

Back mirrors it. Both pages share one name, so only the current one is ever captured.

Three

The pair is clipped to the page box, so the slide never spills over the rest of the view.

List reflow

Rows keep their identity across adds, removals and reorders, so they move instead of flashing. A removed row gets an exit animation CSS transitions cannot give it.

Content crossfade

Text replaced in place fades between old and new.
