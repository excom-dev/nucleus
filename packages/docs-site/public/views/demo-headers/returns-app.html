Furniture Returns

Example of using Quark/CSS to drive very complex business logic without JS.


Return an item or order a replacement part. Who is looking, what they picked, the date and the delivery method all change what is allowed — and every one of those rules is a Quark or CSS rule you can read top to bottom. The data sits in the page as elements that name what they hold — a <data-item> per line, a <data-part> per piece of a bundle — with every field on its own attribute; the rules select on those. No JavaScript to trace, no state to hunt for.
